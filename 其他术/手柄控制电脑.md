在 **macOS** 上用**手柄控制电脑**，分几种玩法，从“能用”到“好用”我给你捋清楚，照着做就行。

---

## 一、最简单：只当“键盘 + 鼠标”

👉 适合：用手柄刷网页、控制播放器、演示、轻度办公

### ✅ 推荐软件（免费 / 稳定）

### **ControllerMate（老牌，但略复杂）**

* 功能：

  * 摇杆 → 鼠标移动
  * 按键 → 键盘快捷键
* 优点：功能极强
* 缺点：学习成本高（像搭积木）

### **Enjoyable（最简单）**

* GitHub 开源
* 能把：

  * 手柄按键 → 键盘按键
* 不能直接当鼠标，但够用

📌 如果你只是想：

> 手柄控制 PPT、暂停播放、翻页
> → **Enjoyable 就够了**

---

## 二、真正把手柄当鼠标用（强烈推荐）

👉 适合：沙发党 / 懒人 / 接电视用 Mac

### ⭐ **Joystick Mapper（付费，最好用）**

* App Store 可买
* 功能：

  * 左摇杆 → 鼠标移动
  * 右摇杆 → 滚轮
  * 扳机 → 左右键
  * 自定义宏、快捷键

**设置思路（典型）**

```
左摇杆 → 鼠标移动
A 键 → 左键
B 键 → 右键
RB/LB → 滚轮
```

👉 这是目前 **mac 上体验最像“手柄操作系统”的方案**

---

## 三、用 Steam（隐藏高手路线）

👉 适合：你本来就装了 Steam

### **Steam → 桌面配置**

Steam 不只是打游戏的，它能：

* 手柄映射 **整个桌面**
* 鼠标、键盘、宏全支持

**步骤**

1. 打开 Steam
2. 设置 → 控制器 → 启用手柄
3. 进入 **Big Picture 模式**
4. 配置「桌面布局」

✔ 优点：免费、功能强
❌ 缺点：得一直开着 Steam

---

## 四、支持哪些手柄？

基本都行：

* ✅ Xbox 手柄（原生支持最好）
* ✅ PS4 / PS5（蓝牙 + Steam 更稳）
* ✅ Switch Pro
* ✅ 国产蓝牙手柄（看运气）

👉 macOS 自带支持 Xbox / PS 系列
