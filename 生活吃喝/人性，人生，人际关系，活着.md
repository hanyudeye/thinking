# 让人喜欢

每次与别人结束对话时，不管话题是什么或多么紧张，她都会说一句或做一件关于对方的好事，让对方最后留下的印象是积极的。

每次对话结束时说一件有关对方的好事，能让别人喜欢你

如果你是男性，想要称赞不熟的女性，最好夸她们主动选择的东西，比如眼妆、穿搭配色、甚至衣服上的logo 。夸身体部位可能有风险，因为你不知道对方是否对那方面感到自卑，而且会显得你很猥琐。我每次称赞女生的指甲都能看到她们的脸亮了起来。我喜欢成为那个注意到她们花心思打扮的小细节的人。

人们在背后说坏话，常常最终会传回到当事人耳里。我意识到这点后，虽然我本来也不喜欢讲坏话，但我开始积极在背后说别人的好话。我不确定这算不算"外挂秘籍"，但如果有人告诉我，有同事或朋友在我不在的时候说了我好话，我一定觉得非常开心。

如何快速与某人建立有意义的关系
1. 赞美他们做得好的事情，越具体越好。
2. 向他们请教如何也能像他们一样把这件事做好。
3. 认真倾听他们的建议，并真正去实践。
4. 后续再找他们反馈你因为采纳他们建议而取得的好结果。
5. 他们会喜欢你、支持你、愿意为你付出。
 甚至在你犯错时也会体谅你。他们可能还会把女儿嫁给你。
 所以只对你真心想建立关系的人使用这个"秘籍"，因为它真的太有用了这世上没有人能完全抵挡这个策略一一只要你足够真诚。

对客服人员非常友好。这听起来很简单，但你会惊讶于光是对他们态度好，就可能获得升级、退款、或更快的帮助。毕竟他们每天都要应付各种怒气冲天的客户。

"你无法控制别人，你只能控制自己的回应。"这是我每天默念的一句话。

## 完成任务

当你在做某项持续性的工作，比如写代码、写书、做手工，结束时不要停在枯燥处，而是停在一个有趣的地方，这样更容易重新/继续开始。

> 当你从事某项任务一天完不成时，一定要保持任务现场，以便下次明天完成

当一项任务太大、让人不知从何开始时，我会告诉自己："只做五分钟。"五分钟准备，五分钟研究，五分钟清理·比起被整个任务吓倒，这样更容易开始。而有时做完五分钟后，你会发现自己突然又有动力继续做下去了。
