# 修改局部颜色

## gimp 文字怎么加边框

GIMP给文字加边框（描边/轮廓）有3种高效方法，适配不同效果需求，以下是可直接操作的步骤与对比：

---

### 方法一：路径描边法（最精准，适合精细轮廓）
1. 输入文字并转路径：选文字工具（T）输入文字，右键文本图层→“从文字创建路径”（Path from Text）。
2. 新建透明层：Shift+Ctrl+N新建图层，命名“文字边框”，填充设为透明。
3. 生成选区并扩展：选中边框层→选择→来自路径（From Path）→选择→扩展（Grow），设2–5像素（边框厚度）。
4. 描边选区：编辑→描边选区（Stroke Selection），选“描边线”，设宽度、颜色、线型（实线/虚线），确定后边框自动生成。
5. 图层管理：将边框层拖到文本层下方，按需调整位置与不透明度。

### 方法二：扩展填充法（适合粗边框/纯色轮廓）
1. 文本转选区：右键文本图层→“Alpha到选区”（Alpha to Selection），得到文字形状选区。
2. 新建边框层：Shift+Ctrl+N新建透明层，移到文本层下方。
3. 扩展选区：选择→扩展（Grow），设3–8像素（边框粗细）。
4. 填充颜色：选前景色→油漆桶工具（Shift+B）填充选区，完成纯色边框。
5. 优化：可添加内发光/外发光增强层次。

### 方法三：图层缩放法（快速粗边框，适合标题大字）
1. 复制文本层：右键文本图层→复制图层，将副本移到原图层下方。
2. 改副本颜色：选副本层→前景色设为边框色（如黑色）。
3. 缩放扩展：图层→缩放图层（Shift+S），按105%–110%缩放（保持比例），让副本略大于原文字。
4. 对齐居中：工具→变换→对齐，选择“与选区中心对齐”，确保边框均匀。
5. 微调：降低副本层不透明度（70%–90%），或添加高斯模糊（半径0.5–1像素）软化边缘。

---

### 常见问题与技巧
|问题|解决方法|
| ---- | ---- |
|边框锯齿/模糊|用路径描边法，选“抗锯齿”；扩展填充时勾选“平滑”|
|边框不均匀|缩放法用“链接宽高”；路径法确保路径转换完整|
|多层边框|重复路径描边步骤，每层设不同颜色/宽度，叠加效果|
|虚线边框|描边选区时选“虚线”，调整间距与长度参数|
