# 六、常用特殊规则（必须掌握）

## 促音（小っ）

双写辅音：

```
gakkou → がっこう
kitte → きって
```

---

## 拗音（きゃ きゅ きょ）

```
kya → きゃ
shu → しゅ
cho → ちょ
```

---

## ん 的输入

```
nn → ん
```

例如：

```
nihon → にほん
```

如果出现错误，用：

```
n + n
```
