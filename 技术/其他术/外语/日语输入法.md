



结论先说清楚：

**微软自带日语输入法（Microsoft IME）不是用“英语拼音”，而是用“罗马字（Romaji）”输入。**
罗马字 ≠ 英语拼音。它是把日语假名按固定规则映射到拉丁字母。

---

# 一、微软日语输入法是什么




* Windows 内置
* 支持：平假名、片假名、汉字转换
* 输入方式：

  * Romaji（默认，推荐）
  * かな输入（直接键盘对应假名，不推荐初学者）

---

# 二、是否“英语拼音”？

不是。

它使用 **罗马字输入规则（Hepburn 系统为主）**，例如：

| 输入   | 输出     |
|--------|----------|
| ka     | か       |
| shi    | し       |
| tsu    | つ       |
| kyo    | きょ     |
| gakkou | がっこう |

规则固定，与英语发音无关。

---

# 三、如何在 Windows 中启用

## 1️⃣ 添加日语键盘

设置路径：

```
Settings → Time & Language → Language & Region → Add language → Japanese
```

安装后会自动带 Microsoft IME。

---

## 2️⃣ 切换输入法

快捷键：

```
Win + Space
```

或：

```
Alt + Shift
```

# 四、使用方法（标准流程）

### 1️⃣ 切换到 日语输入

状态栏会显示：

```
A   （英文模式）
あ  （日语模式）
```

按：

```
Alt + `
```

或点击状态栏切换到「ひらがな」

---

### 2️⃣ 输入罗马字

watashi
```

自动变成：

```
わたし
```

按空格 → 进入汉字转换：

```
私
```

按 Enter 确认。

---

# 五、输入模式说明（关键）

点击任务栏输入法图标 → 可以选择：

* ひらがな（默认，推荐）
* カタカナ
* 半角英数
* 全角英数

**学习阶段只用：ひらがな**

---

# 六、常用特殊规则（必须掌握）

## 促音（小っ）

双写辅音：

```
gakkou → がっこう
kitte → きって
```

---

## 拗音（きゃ きゅ きょ）

```
kya → きゃ
shu → しゅ
cho → ちょ
```

---

## ん 的输入

```
nn → ん
```

例如：

```
nihon → にほん
```

如果出现错误，用：

```
n + n
```

---

# 七、是否适合初学者？

是的。

学习日语 99% 都用 Romaji 输入。

只有母语者或打字极快的人才用 かな键盘。

你正在学日语，而且平时大量在电脑上操作：

建议：

* 强制使用日语 IME 写日记

* 用日语打标签

输入本身会强化假名记忆。
