## 常见指标和术语

| 指标              | 含义          | 用途        |
| --------------- | ----------- | --------- |
| **PE（市盈率）**     | 股价 / 每股收益   | 衡量股票是否被高估 |
| **ROE（净资产收益率）** | 净利润 / 股东权益  | 衡量公司盈利能力  |
| **Beta系数**      | 与大盘波动的对比值   | 越高风险越大    |
| **分红收益率**       | 每年分红 / 当前股价 | 衡量股息回报    |

## 什么是对冲

对冲就是 平时没收益的，股票波动的时候，人们会到债券里面去，那时候债券就涨价了，这就叫对冲。

## 可执行框架

- 60% 宽基指数
- 25% 债券
- 10% 高股息
- 5% 现金

一年再平衡一次。 这比大多数主动操作更稳。
> 不推荐高科技个股，因为指数里科技股的权重已经很高了
