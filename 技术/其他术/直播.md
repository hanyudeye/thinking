# 抖音直播纯录播，无人播会违规

抖音直播**直接用录播素材当直播、纯无人/挂机播放**属于明确违规，会被警告、断播、限流，严重时**永久封禁直播权限**。但**合规使用录播片段作为辅助素材**是允许的，关键是控制占比、真人实时互动、素材合规。


# 索尼α7 直播设置指南（两种方案）
索尼α7系列可通过**USB直连+Imaging Edge Webcam**或**HDMI+采集卡**两种方式用作直播镜头，以下是详细步骤与参数建议。

## 方案一：USB直连（无需采集卡，适合日常直播）
### 1. 相机基础设置
- 模式拨盘切至**动态影像模式**（视频图标），建议用**M档**手动控制参数
- 菜单→【网络】→【智能手机控制】→关闭；【电脑遥控功能】→开启，连接方式选**USB**
- 菜单→【设置】→【USB】→USB连接模式选**USB流式传输**
- 菜单→【拍摄】→【USB流式传输】：分辨率选**1080p 60p**（USB 3.0接口支持），帧率60p，动态影像录制选**禁止**
- 曝光设置：快门1/60（匹配帧率），ISO 400-800（光线不足可略调），白平衡固定（如5200K），开启**人脸/人眼对焦**
- 电源设置：自动关机选**关**，自动关机温度选**高**，避免直播中途断电

### 2. 电脑与软件设置
- 用**USB 3.0 Type-C线**连接相机与电脑（确保接口为USB 3.0，提升传输稳定性）
- 安装并打开**Imaging Edge Webcam**软件，软件识别到α7后，选择输出分辨率1080p 60p
- 打开直播软件（抖音直播伴侣、OBS、视频号等），在“摄像头/视频设备”中选择**Sony Camera (Imaging Edge)**
- 软件设置：分辨率1080p，帧率60p，视频编码选**硬编**，码率8Mbps-10Mbps，色彩空间709，色彩范围**局部**

## 方案二：HDMI+采集卡（画质更稳，适合专业直播）
### 1. 相机设置
- 模式拨盘切至**动态影像M档**，菜单→【设置】→【外部输出】→【HDMI输出设置】：分辨率**1080p**，HDMI信息显示**关**
- 菜单→【拍摄】→【影像质量/记录】：文件格式选MP4，动态影像设置选1080p 60p，编码**420**
- 对焦设置：开启**连续AF**，打开**人脸/人眼优先对焦**，对焦区域选**广域**

### 2. 硬件连接
- 用**HDMI线**连接α7的HDMI输出口与采集卡的HDMI IN
- 用**USB-C线**连接采集卡与电脑（插电脑USB 3.0接口）
- 如需监看，用另一根HDMI线连接采集卡HDMI OUT与显示器

### 3. 直播软件设置
- 打开直播软件，添加“视频采集设备”，选择采集卡型号
- 参数设置：分辨率1080p，帧率60p，视频格式RGB24/YUY2，色彩空间709，色彩范围**局部**
- 音频设置：选择麦克风输入（外接麦克风接采集卡或电脑），扬声器选默认设备

## 通用直播小贴士
1.  供电保障：USB直连建议用**假电池**（外接电源），避免相机耗电过快；HDMI方案确保相机满电或接假电池
2.  画质优化：用补光灯固定光线，背景简洁，适当增加对比度与锐度，避免画面发灰
3.  故障排查：画面卡顿则降低分辨率至1080p 30p；软件识别不到则重启相机与软件，或重新插拔USB线
4.  音频注意：Imaging Edge Webcam不传输相机麦克风音频，需用电脑或外接麦克风收音
