有，而且有不少**纯离线、可全文/整文档翻译**的工具，适合涉密、无网、隐私敏感场景。下面按「易用性、免费/开源、专业度」给你整理最实用的几款，附核心用法。

### 一、免费开源首选（最推荐）
#### 1. Argos Translate（100%离线、跨平台、支持全文/文档）
- **核心优势**：完全本地运行、数据不外传；支持 40+ 语言；自带 GUI、命令行、Python 库；可翻译 TXT、DOCX、PDF、HTML、SRT 字幕。
- **安装（Windows/macOS/Linux）**
  ```bash
  # 安装核心库 + GUI
  pip install argostranslate argostranslategui
  ```
- **使用**
  1. 打开 `argostranslategui`，下载中英/中日等语言模型（单个约 100–300MB）。
  2. 直接粘贴全文，或拖入文档，一键离线翻译。
  3. 命令行批量翻译：
     ```bash
     argos-translate-files --from en --to zh 文档.pdf
     ```
- **适合**：日常办公、技术文档、论文、字幕翻译；隐私要求高。

#### 2. LibreTranslate（本地部署、可自建离线服务）
- **核心优势**：开源、可本地部署；支持全文/API 调用；基于 CTranslate2，速度快；支持中英德法西等主流语言。
- **部署（Docker 一键）**
  ```bash
  docker run -d -p 5000:5000 libretranslate/libretranslate
  ```
- **使用**：浏览器打开 `http://localhost:5000`，粘贴全文翻译；也可通过 API 集成到 Emacs/脚本。

---

### 二、本地大模型方案（翻译质量更高、适合专业文档）
#### 1. Ollama + 翻译模型（如 `translategemma-4b-it`）
- **核心优势**：纯本地大模型；支持 50+ 语言；可翻译长文本、专业术语；CPU 即可运行（16GB 内存）。
- **安装**
  ```bash
  # 安装 Ollama
  curl -fsSL https://ollama.com/install.sh | sh
  # 拉取翻译模型
  ollama pull translategemma-4b-it
  ```
- **全文翻译（命令行）**
  ```bash
  cat 英文文档.txt | ollama run translategemma-4b-it "翻译成中文，保持格式"
  ```
- **适合**：技术论文、合同、长文档；追求接近在线大模型的质量。

#### 2. Hunyuan-MT 7B（国产离线翻译模型、浏览器界面）
- **核心优势**：纯本地、断网可用；支持 PDF/DOCX/TXT 拖入翻译；韩/俄/阿等小语种表现好；浏览器操作，无命令行门槛。
- **获取**：通过 Hugging Face 下载模型，本地启动 WebUI。

#### 1. 有道翻译（离线包）

- **注意**：免费版离线包有字数/功能限制；适合个人日常应急。

#### 2. 同文离线 AI 翻译平台（国产、涉密场景）
- **核心优势**：完全离线、数据本地处理；支持 PDF/Word/图片；百万字文档快速翻译；适合政府/企业保密场景。

### 四、Emacs 集成离线翻译（回到你的需求）
如果你需要在 **Emacs 里纯离线全文翻译**，推荐用 **Argos Translate + Emacs 命令** 组合：

#### 配置示例（init.el）
```elisp
;; 调用 Argos Translate 命令行实现离线全文翻译
(defun my/offline-translate-full-text ()
  (interactive)
  (let ((text (buffer-string)))
    (with-temp-buffer
      (insert text)
      ;; 调用 argos-translate 命令行（离线）
      (shell-command-on-region (point-min) (point-max)
                               "argos-translate --from en --to zh"
                               nil t)
      (switch-to-buffer "*Offline Translation*"))))

;; 绑定快捷键 C-c o
(global-set-key (kbd "C-c o") 'my/offline-translate-full-text)
```

#### 使用
1. 先安装 `argostranslate`（见上文）并下载语言模型。
2. Emacs 中打开文档 → 按 `C-c o` → 离线全文翻译结果在新缓冲区显示。

### 五、选型建议
- **个人日常/隐私优先**：选 **Argos Translate**（免费、GUI+命令行、全平台）。
- **专业长文档/追求质量**：选 **Ollama + translategemma**（本地大模型、离线、接近在线质量）。
- **Emacs 集成**：用 **Argos Translate + 自定义命令**，实现纯离线全文翻译。
- **企业/涉密**：选 **同文离线 AI 翻译平台** 或 **有道翻译企业版**。
