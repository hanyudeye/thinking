# 🧩 1. ellama 是什么？
ellama 是一个 **Emacs 的本地/远程 LLM 客户端**，类似 gptel，但更偏向：

- 本地模型（Ollama）
- 任务式工作流（task）
- 模板（template）
- 角色（role）
- buffer 操作（插入、替换、总结）

它让你在 Emacs 里像用 Copilot 一样和 LLM 交互。

---

# 🛠️ 2. 如何安装 ellama（Spacemacs 版本）

在 `~/.spacemacs` 的 `dotspacemacs/user-config` 中加入：

```elisp
(use-package ellama
  :ensure t)
```

然后 `SPC f e R` 重载配置。

# 🎯 5. 添加你自己的中文提示词（模板方式）

把下面放进你的 `dotspacemacs/user-config`：

```elisp
(use-package ellama
  :config
  ;; 中文总结模板
  (ellama-define-template
    my-cn-summary
    "中文总结"
    "请用自然中文总结下面的内容，要求：
1. 不要使用 AI 腔
2. 控制在 100 字以内
3. 保留最重要的观点
内容如下：\n\n%s")

  ;; 中文代码解释模板
  (ellama-define-template
    my-cn-code-explain
    "中文代码解释"
    "请用简洁中文解释下面的代码，重点说明：
1. 代码在做什么
2. 关键逻辑
3. 潜在问题
不要复述代码本身。
代码如下：\n\n%s")
)
```

### 使用方式：

选中内容 →  
```
M-x ellama-run-template
```

你会看到：

```
my-cn-summary
my-cn-code-explain
```

# 🧩 6. 添加中文“角色”（system prompt）

```elisp
(ellama-define-role
  cn-writer
  "中文写作者"
  "你是一名专业中文写作者，写作要求：
- 自然、清晰、有结构
- 不使用 AI 腔
- 不使用“首先、其次、最后”
- 控制在 80–200 字")
```

使用：

```
M-x ellama-set-role
```

之后所有 ellama 对话都会自动带上这个中文 system prompt。

---

# 🔧 7. 添加中文“任务”（task）

```elisp
(ellama-define-task
  cn-refactor
  "中文代码重构"
  "请按照“可读性 > 性能”的原则重构下面的代码，并解释你的设计取舍。")
```

使用：

```
M-x ellama-run-task
```

# ⚡ 8. 在 Spacemacs 中绑定快捷键（强烈推荐）

```elisp
(spacemacs/set-leader-keys
  "aiS" 'ellama-run-template-my-cn-summary
  "aiE" 'ellama-run-template-my-cn-code-explain
  "aiR" 'ellama-set-role)
```

现在你可以：

```
SPC a i S → 中文总结  
SPC a i E → 中文代码解释  
SPC a i R → 切换中文写作角色  
```
