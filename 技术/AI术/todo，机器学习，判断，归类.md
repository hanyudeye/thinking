## **2）sklearn 官方教程 + 练习**

* 🚩难度：易
* ⏱时间：1～2 周
* 🎯适合：会一点 Python 的人
* ⭐优点：直接带你跑 ML 模型，比课程更“动手”

链接：sklearn 官网 tutorials（你搜一下就有）

重点练：

* 线性回归
**线性回归就是用一条直线，去尽量贴近一堆数据点，从而预测未来值的方法。**

* 逻辑回归
**逻辑回归就是把输入套进一个 S 型函数，让结果变成 0 到 1 的概率，用来判断“属于/不属于某类”的方法。**

* SVM
* 决策树
* 随机森林
* 交叉验证
* 过拟合

跑 6–10 个教程后，你的“模型直觉”会提升非常快。

# 🤖 **二：深度学习（DL）课程推荐**

---

## **1）Fast.ai《Practical Deep Learning for Coders》**

* 🚩难度：中等
* ⏱时间：3–6 周
* 🎯适合：会一点 Python 想“直接动手做项目”的人
* ⭐优点：全网评价最高的“实战派”课程
* **一句话：最快速把你带进深度学习世界的课程。**

---

## **2）吴恩达《Deep Learning Specialization》**

* 🚩难度：中等偏上
* ⏱时间：4–8 周
* 🎯适合：希望系统学习 DL
* ⭐优点：逻辑清晰，是深度学习的“正规军路线”
* 包含：

  * 神经网络基础
  * CNN
  * RNN
  * 优化技巧
  * 项目结构

## **3）PyTorch 官方教程**

* 🚩难度：入门
* ⏱时间：1–2 周
* ⭐优点：学完就能写模型
* 🎯适合：准备做 DL 项目的你

# 🎓 **三：最适合初学者的 AI 书单（不学数学都能看）**

---

## ⭐ **1）《机器学习实战（Hands-On Machine Learning）》—— Aurélien Géron**

* 公认“人人能看懂的 ML 圣经”
* 实战 + 理论完美平衡
* 你如果只选一本看，就选这个

---

## ⭐ **2）《Deep Learning with Python》—— François Chollet（Keras 作者）**

* 非常通俗易懂
* 配套代码很多
* 看完你就能做 CNN、RNN 项目

---

## ⭐ **3）《Dive into Deep Learning (D2L)》**

* 免费电子书
* PyTorch / MXNet 代码齐全
* 全中文也有
* 内容最全面的一本

这是中国学习 AI 的学生最常用的一本书。
