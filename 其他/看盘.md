## 🧭 一、术语概览

| 名称          | 中文解释              | 用途                 |
| ----------- | ----------------- | ------------------ |
| **分时图**     | 每分钟的实时价格走势        | 看**当天行情**和**盘中异动** |
| **日K线图**    | 每天一个蜡烛图           | 看**趋势、支撑压力位**      |
| **多日分时图**   | 连续多天的分时图合并        | 看**短期波动比较**        |
| **周K/月K线图** | 每周/每月一个蜡烛图        | 看**中长期走势**         |
| **分钟K线图**   | 1、5、15、30分钟为单位的K线 | 看**短线节奏**，适合短线操作   |

## 📊 二、各图用途与特点

### 1️⃣ 分时图（实时走势图）

* **展示内容**：横轴为时间（如09:30-15:00），纵轴为价格或涨跌幅。
* **常带有**：成交量、均价线。
* **用途**：

  * 看当天市场情绪、资金是否活跃。
  * 判断是否有突然拉升或下杀。
  * 辨别高开低走 or 低开高走。

📌 **适合人群**：做日内交易、观察资金动向。

---

### 2️⃣ 多日分时图（有时叫“多日走势图”）

* **展示内容**：把最近3～5天的分时图叠加对比。
* **用途**：

  * 看某只股票是否连续强/弱。
  * 比较每日涨跌幅度、波动位置。
  * 辅助判断是否出现连涨、连跌、震荡状态。

📌 **适合人群**：做短线、次日买入策略的人。

---

### 3️⃣ K线图（日K、周K、月K）

#### 每个 K 线柱体表示：

* **开盘价、收盘价、最高价、最低价**（通常红涨绿跌）

#### 常见周期：

* **日K**：分析日趋势。
* **周K**：中期方向，主力进退信号。
* **月K**：长期趋势，适合价值投资者或趋势跟踪者。

#### 搭配指标：

* MACD、均线（MA5/10/20）、布林线、成交量等

📌 **适合人群**：中长期持股者、技术分析爱好者。

---

### 4️⃣ 分钟K线（1分钟、5分钟、15分钟）

* 展示非常细的走势，适合**短线操作**、**高频交易者**
* 可以发现更精细的买卖点
* 波动快，噪音多

📌 **适合人群**：做T、打板、短线高手

---

## 🎯 三、如何组合使用它们？

| 目的         | 使用方式                         |
| ---------- | ---------------------------- |
| 想知道今天股票强不强 | 看“分时图”是否高开高走、有无放量            |
| 想判断买点/卖点   | 看“日K + 均线系统”是否形成金叉、突破        |
| 做短线进出      | 看“5分钟K线 + 分时量能”              |
| 做中线布局      | 看“周K + 月K + 均线趋势”            |
| 找趋势拐点      | 结合“K线 + 成交量 + MACD 或 RSI”等指标 |

---

## 📌 举个简单例子：

你看到一只股票 **今天突然拉涨停**，可以这样看：

1. **分时图**：看拉升是否突然，量能是否配合。
2. **多日图**：这几天是不是连续走强？
3. **日K图**：是否突破前高？还是横盘后启动？
4. **周K图**：处于长期上升通道还是下跌反弹？

---

## ✅ 总结一句话：

> **分时图看“情绪”和“波动”，K线图看“趋势”和“结构”，多日图看“连续性”。** 看盘时要结合多个视角，更全面地理解市场行为。 -->
