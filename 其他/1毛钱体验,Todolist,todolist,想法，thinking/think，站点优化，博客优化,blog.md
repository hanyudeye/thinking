## 测试服务器在各地的速度
> 理论上，离服务器的直线距离越远，访问速度越慢

**1. 使用在线测速工具**
这些平台会在全球多个节点访问你的网站，并返回加载时间、响应时间等数据。常用的有：

* **[Pingdom Tools](https://tools.pingdom.com/)**（可选地区有限，但界面简单）
* **[Dotcom-Tools](https://www.dotcom-tools.com/website-speed-test.aspx)**（可测试多个国家的速度）
* **[Uptrends](https://www.uptrends.com/tools/website-speed-test)**（节点覆盖全球）
* **[KeyCDN Website Speed Test](https://tools.keycdn.com/speed)**（支持欧洲、美洲、亚洲等地区）

**2. 用命令行自己测**（适合技术人员）

* **ping 或 curl**

  ```bash
  ping example.com
  curl -o /dev/null -s -w '%{time_connect} %{time_starttransfer} %{time_total}\n' https://example.com
  ```
