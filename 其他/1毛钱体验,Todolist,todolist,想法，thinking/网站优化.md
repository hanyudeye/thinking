在个人博客里优化 `<head>` 标签的内容，主要是为了 **提升 SEO、加快页面加载速度、提高社交分享体验**。下面我给你一个比较系统的优化思路：

---

## 1. 基础必备标签

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>你的博客标题</title>
  <meta name="description" content="简短精准的页面描述，不超过 160 字。">
  <meta name="keywords" content="关键词1, 关键词2, 博客, 技术文章">
  <link rel="canonical" href="https://yourblog.com/post-url">
  <link rel="icon" href="/favicon.ico">
</head>
```

* `charset` 保证中文正常显示。
* `viewport` 适配移动端。
* `title` 控制页面标题，最好包含关键词。
* `description` 出现在搜索结果摘要中。
* `keywords` 搜索引擎参考度下降，但可以加上。
* `canonical` 避免重复内容收录。
* `favicon` 提升用户体验。

---

## 2. SEO 优化标签

```html
<meta name="robots" content="index, follow">
<meta name="author" content="你的名字">
<link rel="sitemap" type="application/xml" href="/sitemap.xml">
```

* `robots` 控制搜索引擎抓取。
* `author` 可以加上作者名。
* `sitemap` 提示搜索引擎更快索引。

---

## 3. 提升社交分享体验（Open Graph & Twitter Card）

```html
<meta property="og:title" content="文章标题">
<meta property="og:description" content="文章摘要">
<meta property="og:type" content="article">
<meta property="og:url" content="https://yourblog.com/post-url">
<meta property="og:image" content="https://yourblog.com/images/post-cover.jpg">

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="文章标题">
<meta name="twitter:description" content="文章摘要">
<meta name="twitter:image" content="https://yourblog.com/images/post-cover.jpg">
```

* Open Graph（Facebook、LinkedIn、微信等会用）
* Twitter Card（推特分享时美观）

---

## 4. 性能优化相关标签

```html
<link rel="preload" href="/css/main.css" as="style">
<link rel="preload" href="/js/main.js" as="script">
<link rel="dns-prefetch" href="//cdn.example.com">
<link rel="preconnect" href="//cdn.example.com" crossorigin>
```

* `preload` 提前加载关键资源。
* `dns-prefetch` & `preconnect` 提前建立网络连接，减少延迟。

---

## 5. PWA & 移动端优化（可选）

```html
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#ffffff">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
```

* `manifest` 配合 Service Worker 让网站支持 PWA。
* `theme-color` 改变移动端浏览器地址栏颜色。
* `apple-mobile-web-app` 优化 iOS Safari 添加到桌面后的效果。

---

✅ 建议做法：

* 写一个通用的 `<head>` 模板，然后在不同文章页面动态注入 `title`、`description`、`og:image` 等信息。
* 保持标签简洁，避免无效的 `meta` 堆叠。
* 测试工具：可以用 [Google Lighthouse](https://developers.google.com/web/tools/lighthouse/) 或 [Meta Tags Analyzer](https://metatags.io/) 检查效果。
