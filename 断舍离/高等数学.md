## 初等数学的重要知识点一览

根据 Wikipedia，“初等数学”涵盖的主要内容包括：数感与计数、空间感、方程与公式、数据、二维几何、比例、解析几何、负数、指数与根式、画图几何、相似与全等、三维几何、有理数、函数与模式、斜率与三角等主题 ([维基百科][1])。

中文维基还总结了常见的基础代数、几何与数论内容，如：

* **基础代数**：平方根、比例、分配律、方程（一次、二次、三次、四次）、恒等式、因式分解、一元二次方程、韦达定理等。
* **基础几何**：包括圆的性质（半径、直径、弧、弦、切线等）、周长、面积、勾股定理、正弦定理、余弦定理、角平分线定理等。
* **初等数论**：素数、因数、最大公因数、同余、欧拉函数、小费马定理、中国剩余定理等 ([维基百科][2])。

## 核心公式汇总

下面列出一些最常见、最基础的初等数学公式，覆盖代数、几何与三角等关键领域：

### 代数与因式分解

* $a^2 - b^2 = (a + b)(a - b)$
* $a^2 \pm 2ab + b^2 = (a \pm b)^2$
* $a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$
* 一元二次方程$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$，与根与系数关系：$x_1 + x_2 = -\frac{b}{a}$, $x_1 x_2 = \frac{c}{a}$ ([CSDN][3])。

### 指数与对数

* $a^n \cdot a^m = a^{n+m}$; $a^n / a^m = a^{n-m}$; $(a^n)^m = a^{nm}$; $(ab)^n = a^n b^n$; $a^{-n} = \frac{1}{a^n}$
* 对数基本性质：$\log_a1 = 0$; $\log_a(xy) = \log_a x + \log_a y$; $\log_a \frac{x}{y} = \log_a x - \log_a y$; $\log_a x^y = y \log_a x$; 换底公式：$\log_a x = \frac{\ln x}{\ln a}$ ([CSDN][3])。

### 三角恒等式

* $\sin^2 \alpha + \cos^2 \alpha = 1$ 是最基本的关系。【更多公式可展开覆盖和差公式、倍角公式、诱导公式等】 ([CSDN][3])。

### 平面几何定理

* **角平分线定理**：三角形中角的平分线将对边分成邻边长度的比例 ([维基百科][4])。
* **勾股定理、正弦定理、余弦定理**：在基础几何中极为重要，也常应用于高中内容 ([维基百科][2])。
