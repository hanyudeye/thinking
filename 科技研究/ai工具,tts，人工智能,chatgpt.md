# IndexTTS
B站的一款TTS要出来了，IndexTTS，在词错误率上超过了CosyVoice2、Fish-Speech、F5-TTS等

IndexTTS基于XTTS和Tortoise开发，并做了改进
中文字符—拼音混合建模，可以直接输入拼音来纠正多音字的发音错误

结合Conformer条件编码器和BigVGAN2语音解码器，提高了训练稳定性、音色相似性以及声音质量

# chatgpt 锦囊妙计

- **直接提问** https://chatgpt.com/?q=請問滑鼠病了是不是應該吃老鼠藥？
- **使用搜索功能** https://chatgpt.com/?hints=search&q=台北市天氣
    加上 **hints=search** 参数
- **使用临时交谈** https://chatgpt.com/?hints=search&temporary-chat=true&q=台積電股價
   使用 **temporary-chat=true** 参数
- **挑选 ChatGPT 模型** https://chatgpt.com/?hints=search&model=gpt-4o&q=台北市最好吃的牛肉麵，顯示在地圖上
   model=gpt-4o-mini，gpt-4o，gpt-4
- **设为默认搜索引擎 或 加入浏览器书签**
 https://www.chatgpt.com/?hints=search&model=gpt-4o-mini&q=%s

   - 今日天气 https://www.chatgpt.com/?hints=search&temporary-chat=true&model=gpt-4o-mini&q=今日天气 ，上海
