## markdown 表格 处理

查找 | 分隔的表格：
```
 <!-- 查找一个 **竖线** -->
  |([^|]+)

 <!-- 查找3个 **竖线** -->
\|([^|]+)\|([^|]+)\|([^|]+)\|
```

替换内容
```
<!-- 仅保留1，3列的内容 -->
|$1|$3|
<!-- 替换成列表格式->
- [$1]($2)
```
## 列表操作

```
<!-- 查找列表中多余的空格 -->
- \[\s*(.*?)\s*\]\(\s*(.*?)\s*\)
```
