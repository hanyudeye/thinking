采用设置键盘快捷键的方式，把能用键盘操作的都换成键盘操作

## 键盘控制鼠标移动，点击

使用 ahk 脚本

```
; 使用箭头键移动鼠标
Up::MouseMove, 0, -10, 0, R
Down::MouseMove, 0, 10, 0, R
Left::MouseMove, -10, 0, 0, R
Right::MouseMove, 10, 0, 0, R

; Z 键左键点击，X 键右键点击
z::Click
x::Click right
```

```
; 使用箭头键移动鼠标
#Up::MouseMove, 0, -10, 0, R
#Down::MouseMove, 0, 10, 0, R
#Left::MouseMove, -10, 0, 0, R
#Right::MouseMove, 10, 0, 0, R

#k::MouseMove, 0, -10, 0, R
#j::MouseMove, 0, 10, 0, R
#h::MouseMove, -10, 0, 0, R
#l::MouseMove, 10, 0, 0, R

; Z 键左键点击，X 键右键点击
#z::Click
#x::Click right
```

## 配置  代理切换快捷键

v2rayN 中设置热键 ，**Alt + Ctrl + S** 设置代理，**Alt + Ctrl + D** 清除代理

## vscode 显示，隐藏 左侧活动栏

keybindings.json
```
	{
		"key": "ctrl+b",
		"command": "workbench.action.toggleSidebarVisibility"
	},
```	

## tmux 多个终端操作

``` tmux
PREFIX + c  创建工作区
PREFIX + | 或 -  创建水平或垂直终端 vertical
```

## vim 文本操作

``` vim

:w !sudo tee %  - 执行 sudo 保存文件
> :w !{cmd} 让 Vim 将当前缓冲区的内容作为标准输入传递给外部命令 {cmd}
> tee 命令将标准输入的内容写入指定文件（这里是当前文件）。
> % 是 Vim 中表示当前编辑文件路径的寄存器。
```
