采用设置键盘快捷键的方式，把能用键盘操作的都换成键盘操作

## 键盘控制鼠标移动，点击

使用 ahk 脚本

```
; 使用箭头键移动鼠标
Up::MouseMove, 0, -10, 0, R
Down::MouseMove, 0, 10, 0, R
Left::MouseMove, -10, 0, 0, R
Right::MouseMove, 10, 0, 0, R

; Z 键左键点击，X 键右键点击
z::Click
x::Click right
```

```
; 使用箭头键移动鼠标
#Up::MouseMove, 0, -10, 0, R
#Down::MouseMove, 0, 10, 0, R
#Left::MouseMove, -10, 0, 0, R
#Right::MouseMove, 10, 0, 0, R

#k::MouseMove, 0, -10, 0, R
#j::MouseMove, 0, 10, 0, R
#h::MouseMove, -10, 0, 0, R
#l::MouseMove, 10, 0, 0, R

; Z 键左键点击，X 键右键点击
#z::Click
#x::Click right
```

## 配置  代理切换快捷键

v2rayN 中设置热键 ，**Alt + Ctrl + S** 设置代理，**Alt + Ctrl + D** 清除代理


``` 
    {
      "eGlobalHotkey": 1,
      "Alt": true,
      "Control": true,
      "Shift": false,
      "KeyCode": 68
    },
    {
      "eGlobalHotkey": 2,
      "Alt": true,
      "Control": true,
      "Shift": false,
      "KeyCode": 83
    },
```

		"command": "workbench.action.toggleSidebarVisibility"
