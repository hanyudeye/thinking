# 一、先把问题拆清楚（关键）

你现在的约束本质是：

* 工作成长性差（技能不复利）
* 市场竞争力不突出（跳槽困难）
* 时间被工作消耗（学习空间有限）

这类状态的核心矛盾是：

> 你在“消耗型岗位”，而不是“资产型岗位”

资产型岗位特征：

* 技能会复利增长（工程 / 数据 / AI / 产品）
* 可迁移到更高薪公司
* 能形成作品或成果

---

# 二、优先级最高的方向（不要分散）

## 第一目标：提升“可卖技能”

不是学很多东西，而是选一个方向做到能换工作：

### 推荐三条现实路线（选一条）

#### 1. 后端 / 全栈（最稳）

你已经学 Node.js，这条是合理的：

重点能力：

* API 设计
* 数据库（MySQL / PostgreSQL）
* Redis 基础
* 项目部署（Docker）

目标：

> 能独立做一个可上线的项目

---

#### 2. AI应用开发（更高溢价）

现在市场需求更强：

重点：

* LLM API（OpenAI / Claude）
* RAG（向量数据库）
* Agent workflow
* 简单模型调用 + 产品化

目标：

> 做“AI工具类产品”

---

#### 3. 自动化 / 工具开发（你其实很适合）

结合你之前兴趣（AHK / Windows工具）：

* 自动化脚本
* 桌面工具
* 浏览器插件
* 小型 SaaS

目标：

> 做可卖工具（甚至副业）

# 三、第二目标：把“工作”变成可跳板

# 五、最关键的现实策略（很多人忽略）

# 六、收入提升的本质公式

你要记住这个结构：

> 收入 = 市场价值 × 可替代性 × 议价能力

你现在的问题是：

* 市场价值低（岗位限制）
* 可替代性高（技能浅）
* 议价能力弱（跳槽困难）

所以要做的是：

---

## 1. 提高市场价值

→ 学可招聘技能（Node / AI / 全栈）

---

## 2. 降低可替代性

→ 做项目 / 作品 / 产品

---

## 3. 提高议价能力

→ 能跳槽才有工资上涨空间

---
