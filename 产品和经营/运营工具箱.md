# 三、真正有价值的清理项（重点）

普通 temp 没意义。

真正有效的是：

---

## 1. Windows Update 残留（巨大）

```text
C:\Windows\SoftwareDistribution\Download
```

还有：

```powershell
Dism.exe /online /Cleanup-Image /StartComponentCleanup
```

价值非常高。

---

## 2. WinSxS 清理

很多人几十 GB。

用：

```powershell
Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore
```

和：

```powershell
Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase
```

---

## 3. 微信缓存（最关键）

国内用户巨大痛点。

路径：

```text
Documents\WeChat Files
```

视频缓存经常几十 GB。

这个最有市场。

---

## 4. 浏览器缓存

Chrome / Edge：

```text
AppData\Local\Google\Chrome\User Data\Default\Cache
```

---

## 5. NVIDIA 缓存

很多人不知道：

```text
NVIDIA\DXCache
```

---

## 6. 临时文件

```text
%temp%
temp
prefetch
```

只是基础功能。

---

## 7. 休眠文件（巨大）

```powershell
powercfg -h off
```

可能直接释放：

* 8GB
* 16GB
* 32GB

很震撼。

---

## 8. 系统还原点

高级模式里。
