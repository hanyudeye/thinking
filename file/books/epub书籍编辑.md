### 二、核心工具操作指南（快速上手）
#### 1. Sigil（精细排版首选，开源免费）
- 适用场景：修正格式错乱、批量调整样式、生成合规目录
- 快速操作：
  1. 打开 Sigil → 导入 EPUB，左侧“书籍浏览器”查看 HTML/CSS/图片等资源；
  2. 双击章节进入 WYSIWYG 编辑或切换“代码视图”改 HTML/CSS；
  3. 工具→目录→生成目录，按 h1-h6 层级设置 NCX/TOC；
  4. 编辑→元数据，填写 ISBN/作者/封面等，保存即生成合规 EPUB。
- 优势：输出严格符合 EPUB 规范，插件生态丰富，适合平台投稿。

#### 2. Calibre（日常轻量编辑，新手友好）
- 适用场景：改书名/作者/封面、快速修正错字、格式转换后微调
- 快速操作：
  1. 导入 EPUB → 右键“编辑书籍”进入内置编辑器；
  2. 左侧文件树选 HTML 章节改文本，或用“样式”面板调字体/行距；
  3. 改完点“保存”，自动重打包为 EPUB；
  4. 额外需求：用“转换书籍”批量处理格式，或“修改元数据”批量改标签。
- 局限：专业排版能力弱于 Sigil，适合快速修改变更。

#### 3. Calibre 进阶：命令行批量编辑（适合批量处理）
```bash
# 示例：批量修改元数据（作者）
ebook-meta "book.epub" --author "New Author"
# 示例：转换格式并嵌入字体
ebook-convert input.docx output.epub --embed-all-fonts
```

#### 4. ePUBee 智多星（Word 重度用户）
- 操作：安装插件后，Word 编辑内容→插件→生成 EPUB，支持导入 EPUB 编辑文本与元数据，适合快速批量产出。

### 三、常见问题与排查
1. **编辑后格式错乱**
   - 用 Sigil 打开检查 HTML 标签闭合、CSS 路径，工具→验证 EPUB 检查合规性；
   - 避免手动解压重打包（易破坏文件结构），优先用工具导出。
2. **EPUB3 兼容性问题**
   - Sigil/InDesign 选择 EPUB3 输出，关闭 EPUB2 兼容模式；
   - 用 Calibre 转换时勾选“启用 EPUB3 支持”。
3. **批量处理需求**
   - 非技术用户用 Calibre 批量转换/元数据编辑；
   - 技术用户用 Pandoc 写脚本批量生成/修改，或用 Python 的 ebooklib 库定制化处理。

---

### 四、选择建议
- 新手/轻量编辑：选 Calibre，兼顾管理与快速编辑，零学习成本；
- 专业排版/平台投稿：选 Sigil，确保 EPUB 合规且样式可控；
- 出版级/富媒体需求：选 InDesign，适合学术/画册类高质量输出；
- Word 重度用户：选 ePUBee 智多星，用熟悉的 Word 完成编辑与转换。
