## OPML 转 XML

 OPML（Outline Processor Markup Language）本身就是一种基于 XML 的格式。因此，**OPML 文件其实就是 XML 文件**，只不过是特定结构的 XML，通常用于订阅源（RSS）、大纲笔记、思维导图等。

---

### ✅ 什么意思是“OPML 转 XML”？

> 实际上，你**不需要转换**，因为 `.opml` 文件就是 `.xml` 文件。你只需**更改文件扩展名**或将其当 XML 文件解析即可。

---

### ✅ 示例：OPML 格式就是 XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<opml version="2.0">
  <head>
    <title>My RSS Subscriptions</title>
  </head>
  <body>
    <outline text="Tech Blogs" title="Tech Blogs">
      <outline text="OpenAI Blog" type="rss" xmlUrl="https://openai.com/blog/rss.xml" />
      <outline text="Google AI" type="rss" xmlUrl="https://ai.googleblog.com/feeds/posts/default" />
    </outline>
  </body>
</opml>
```

你可以看到它本质就是一个符合 XML 语法规范的文件。

---

### ✅ 如何“转换”？

| 操作             | 方法                                     |
|------------------|------------------------------------------|
| 将 `.opml` 变成 `.xml` | **改文件后缀名**为 `.xml` 即可              |
| 用代码解析 OPML  | 使用任意 XML 解析库（如 Python 的 `xml.etree.ElementTree`） |
| 转成通用 XML 结构 | 手动或用脚本提取 `outline` 标签数据，改造成你想要的结构 |

---

### ✅ 示例：Python 解析 OPML（当成 XML）

```python
import xml.etree.ElementTree as ET

tree = ET.parse('example.opml')
root = tree.getroot()

for outline in root.findall('.//outline'):
    print(outline.attrib.get('text'), outline.attrib.get('xmlUrl'))
```

---

### ✅ 如果你想转成自己的 XML 格式？
比如你想把 RSS OPML 转成下面这种自定义格式：

```xml
<feeds>
  <feed name="OpenAI Blog" url="https://openai.com/blog/rss.xml"/>
  <feed name="Google AI" url="https://ai.googleblog.com/feeds/posts/default"/>
</feeds>
```
