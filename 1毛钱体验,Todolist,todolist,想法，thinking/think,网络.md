# 为什么域名 添加 www 前缀能访问，不加就访问不了

这种情况一般是你的域名 **DNS 解析记录** 配置不完整造成的。
你可以把它理解成：

* **`www.example.com`** 和 **`example.com`** 其实是两个不同的域名（`www` 是一个子域名）。
* 你的 DNS 里可能只添加了 `www` 的解析记录，没有给根域名（裸域名）加解析，所以不加 `www` 时无法访问。

---

### 常见原因

1. **DNS 只解析了 `www` 子域**

   * 解析记录里只有：

     ```
     主机记录：www
     记录类型：A
     记录值：你的服务器 IP
     ```

     没有：

     ```
     主机记录：@
     记录类型：A
     记录值：你的服务器 IP
     ```

     “@” 表示根域名（裸域名）。

2. **服务器端只绑定了 `www` 域名**

   * Web 服务器（Nginx、Apache 等）的虚拟主机配置里只绑定了 `www.example.com`，没有绑定 `example.com`。

3. **CDN 或域名服务商限制裸域跳转**

   * 有些 CDN 或云解析（比如 Cloudflare 免费版）要求你手动设置从裸域跳转到带 `www` 的域名，否则不会自动生效。

---

### 解决方法

1. **DNS 添加裸域解析**

   * 在 DNS 管理里增加一条：

     ```
     主机记录：@
     记录类型：A（或 CNAME，如果支持）
     记录值：你的服务器 IP（或指向 www.example.com）
     ```

2. **服务器绑定两个域名**

   * 在虚拟主机配置里同时绑定：

     ```
     server_name example.com www.example.com;
     ```

3. **做跳转**（推荐）

   * 选一个主域名（带或不带 www），然后在服务器或 CDN 里做 301 重定向。
   * 这样搜索引擎不会认为是两个网站，也方便 SEO。
