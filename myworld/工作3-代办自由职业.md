# 💰 四、收入怎么来的？怎么算？

收入完全取决于你接多少活。

常见方式：

### **按项目**

比如：

* 一个剪辑：80～200 RMB
* 文案一篇：50～200 RMB
* 一个 WordPress 网站：2000～8000 RMB
* 一个小程序：6000～15000 RMB
* 一个 Node.js 小工作：300～1500 RMB

### **按月**

客户给你固定月薪（远程工作）：

* 4000～12000 RMB 不等
  适合技术类、运营类。

### **按小时（国际平台）**

* $10～$50/hour（美国客户更高）
  适合设计、程序、剪辑。
