## 一、最简单：Windows 自带【语音访问】（推荐先用）

适合：**开关程序、点按钮、打字**

### 开启方法（Win11 / 新版 Win10）

1. **设置 → 辅助功能 → 语音**
2. 打开 **语音访问（Voice Access）**
3. 选择语言（中文 / 英文）

### 能干什么
你可以直接说：

* **“打开 Chrome”**
* **“关闭窗口”**
* **“向下滚动”**
* **“点击 确定”**
* **“输入 Hello world”**

📌 优点

* 系统级，稳定
* 不用装软件

📌 缺点

* 自动化能力一般
* 对中文识别不如英文稳

👉 **适合日常控制电脑**

---

## 二、键盘语音：Windows【语音输入】

适合：**写文档、写代码注释、聊天**

### 快捷键

```
Win + H
```

你说话 = 打字

📌 常用语音命令（中文）

* “逗号”
* “句号”
* “换行”
* “删除”

👉 你做脚本、写文案、拆书，其实**能省很多手敲**

---

## 三、进阶自动化：语音 → 热键 → 程序

适合：**你这种爱折腾、用 AHK、电脑用得重的人**

### 核心思路

```
你说一句话
↓
识别成文字
↓
触发快捷键
↓
AHK / 程序执行
```

### 工具组合（经典）

* **VoiceAttack**（语音识别）
* **AutoHotkey**（动作执行）

### 能做到什么

你说：

* “开始剪视频”
  → 打开剪映 + 全屏

* “导出视频”
  → Ctrl+E → 回车 → 等待

* “夜间模式”
  → 屏幕亮度 ↓ + 深色模式

📌 这已经是**半个贾维斯**

## 四、真正解放双手：第三方语音控制软件

适合：**长时间电脑工作、想减少键盘鼠标**

### 常见能力

* 自定义命令
* 宏操作
* 控制任意程序

关键词你去搜：

* “Windows voice control software”
* “Voice macro windows”

📌 缺点
