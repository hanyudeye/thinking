## 经济规律

- 供求关系决定价格
- 价值规律（适用于商品经济）
  * 劳动效率高 → 成本低 → 价格更有竞争力；
  * 劳动效率低 → 成本高 → 商品滞销甚至亏损。
- 边际效用递减规律（消费行为）
对同一种商品，**越往后消费，带来的满足感越小**。
- 比较优势规律（国际贸易）
* **内容**：一个国家即使在所有商品上都不如另一个国家高效，也应专注于**自己相对更擅长的领域**。
- 帕累托最优（资源配置）
* **内容**：当资源配置使得**无法在不使任何人变差的前提下让某些人变好**，就达到了最优状态。
- 经济周期规律

* **内容**：资本主义市场经济中，经济运行呈周期性波动，经历扩张、高峰、衰退、复苏。
- 优胜劣汰规律（市场竞争）
  * 新技术、新模式不断替代旧产业；
- 二八定律（帕累托法则）
- 幸存者偏差 （多看失败案例）

## 常见指标和术语

| 指标              | 含义          | 用途        |
| --------------- | ----------- | --------- |
| **PE（市盈率）**     | 股价 / 每股收益   | 衡量股票是否被高估 |
| **ROE（净资产收益率）** | 净利润 / 股东权益  | 衡量公司盈利能力  |
| **Beta系数**      | 与大盘波动的对比值   | 越高风险越大    |
| **分红收益率**       | 每年分红 / 当前股价 | 衡量股息回报    |


## 买股票时机

> **最容易获利的买点，
> 在「下降 → 横盘 → 刚开始上升」的那个阶段。**

不是纯下跌
不是已经涨很久
而是**趋势刚刚反转**的时候。

普通人最稳的做法（不追高、不抄底）
一个简单可执行的思路：

1️⃣ 等它不再创新低
2️⃣ 等它横一段时间
3️⃣ 等它向上突破
4️⃣ 买
5️⃣ 止损放在突破失败的位置

你赚的是：

大概率
小亏大赚
可重复
