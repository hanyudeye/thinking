* **第一性原则：不爆仓**
  回撤控制 > 收益率。避免高杠杆叠加高波动。

* **长期复利靠两点**
  低成本（费率、税、滑点） + 长期持有。

* **区分三类钱**
  生活保障金 / 长期投资 / 高风险尝试（仓位隔离）。

* **少做预测，多做配置**
  预测宏观很难；分散、再平衡更可控。

* **用简单标的打底**
  指数ETF（如 QQQ）做核心，个股作为卫星仓位。


# 最后一条现实原则

```text
少做大决策，多做小试错
```

大多数人卡住，是因为：

* 想一步到位
* 想选“最优路径”

更有效的是：

```text
快速试 → 小成本错 → 保留有效路径
```
